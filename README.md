# interview-prep

Algo Notes: an interview study desk with a Top Interview 150 DSA library, a study plan, and a system design guide.

## Live site

Visit: https://interview-prep.kumarrishav28.workers.dev/#study-plan

## Theory library

Every DSA category has a dedicated theory page (overview, plain-English explanation, core algorithms with Java code, worked examples, pitfalls, and linked practice problems). Open it from the **Theory** tab, the book icon beside each category in the DSA library, or the category label on any problem. Pages live at `#theory/<category>`, for example `#theory/two-pointers`. Content is in `src/data/theory/`.

## Run locally

```
npm install
npm run dev
```

Build for production with `npm run build`. The output goes to `dist/`.
